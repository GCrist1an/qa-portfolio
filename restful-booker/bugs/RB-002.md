# RB-002 — Se acepta una reserva con fecha de salida anterior a la de entrada

| Campo | Valor |
|---|---|
| **Módulo** | Reservas — `POST /booking` |
| **Tipo** | Funcional / Datos |
| **Severidad** | Media |
| **Prioridad** | Media |
| **Entorno** | Newman (CLI) · https://restful-booker.herokuapp.com · ejecución 2026-11-07 |
| **Estado** | Nuevo |
| **Commit de corrección** | — |

## Descripción
La API crea reservas donde `checkout` es anterior a `checkin`. Así se guardan reservas con una duración negativa, que son datos inconsistentes.

## Pasos para reproducir
1. Enviar `POST /booking` con este cuerpo:
   ```json
   {
     "firstname": "Cristian", "lastname": "QA", "totalprice": 250, "depositpaid": true,
     "bookingdates": { "checkin": "2026-12-10", "checkout": "2026-12-01" },
     "additionalneeds": "Breakfast"
   }
   ```
2. Revisar la respuesta.

## Resultado esperado
`400 Bad Request` indicando que `checkout` debe ser posterior a `checkin`.

## Resultado obtenido
`200 OK` y la reserva se crea (devuelve un `bookingid` nuevo) con las fechas invertidas.

## Causa raíz
Sin determinar. No se valida el orden de las fechas. No aplica: la API es de terceros y no tenemos acceso al código. Queda reportado para el equipo responsable.

## Corrección aplicada
No aplica: la API es de terceros y no tenemos acceso al código. Queda reportado para el equipo responsable.
