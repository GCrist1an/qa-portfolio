## Descripción
Cuando faltan campos obligatorios, la API no valida la petición y devuelve un error interno del servidor (500) en lugar de un error de validación (400) que diga qué campos faltan.

## Pasos para reproducir
1. Enviar `POST /booking` con `Content-Type: application/json` y este cuerpo:
   ```json
   { "firstname": "Solo nombre" }
   ```
2. Revisar el código de estado y el cuerpo de la respuesta.

## Resultado esperado
`400 Bad Request` con un mensaje que diga qué campos obligatorios faltan (`lastname`, `totalprice`, `depositpaid`, `bookingdates`).

## Resultado obtenido
`500 Internal Server Error`, cuerpo: `Internal Server Error`.

## Causa raíz
Sin determinar. Parece que falta validar la entrada antes de guardar los datos. No aplica: la API es de terceros y no tenemos acceso al código. Queda reportado para el equipo responsable.

## Corrección aplicada
No aplica: la API es de terceros y no tenemos acceso al código. Queda reportado para el equipo responsable.
