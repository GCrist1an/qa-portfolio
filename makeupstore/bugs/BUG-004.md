# BUG-004 — Las imágenes subidas desde el admin no aparecen en la tienda en vivo

| Campo | Valor |
|---|---|
| **Módulo** | Panel de administración / M2 Catálogo |
| **Tipo** | Despliegue / Integración |
| **Severidad** | Alta |
| **Prioridad** | Alta |
| **Entorno** | Producción (Vercel) |
| **Estado** | ✅ Verificado |
| **Commits de corrección** | `1d99ab8`, `2e260dc`, `3af8e99` |

## Descripción
Las fotos nuevas de productos respondían 404 en producción. Además, una imagen `.webp` estaba dañada y se mostraba vacía.

## Pasos para reproducir
1. Subir una imagen nueva desde el panel admin.
2. Publicar.
3. Abrir el producto en la tienda en vivo.

## Resultado esperado
La imagen se muestra correctamente. Si una imagen falla, se muestra una imagen de respaldo.

## Resultado obtenido
404 en la imagen y producto sin foto.

## Causa raíz
Las imágenes nuevas no se servían por la configuración de rutas del despliegue.

## Corrección aplicada
- Nuevo endpoint `api/image.js` y reglas en `vercel.json` para servir las imágenes.
- Reparación del archivo `.webp` dañado.
- Imagen de respaldo cuando una foto no carga.

## Verificación
- [x] Las imágenes nuevas cargan en producción.
- [x] Con una URL de imagen inválida se muestra la imagen de respaldo.
