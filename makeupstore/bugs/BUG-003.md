# BUG-003 — Publicar desde el panel admin falla cuando el catálogo supera 1 MB

| Campo | Valor |
|---|---|
| **Módulo** | Panel de administración → publicación vía GitHub |
| **Tipo** | Integración / API |
| **Severidad** | Alta |
| **Prioridad** | Alta |
| **Entorno** | Producción (Vercel + API de GitHub) |
| **Estado** | ✅ Verificado |
| **Commit de corrección** | `1cda08d` |

## Descripción
Cuando el archivo del catálogo creció por encima de 1 MB, el panel de administración dejó de publicar cambios.

## Pasos para reproducir
1. Tener un `catalog.json` mayor a 1 MB.
2. Modificar un precio desde el panel admin.
3. Publicar los cambios.

## Resultado esperado
El cambio se publica y se refleja en la tienda.

## Resultado obtenido
La publicación falla porque no se puede leer el catálogo actual.

## Causa raíz
El catálogo se leía desde la API de contenidos de GitHub en formato base64, que no devuelve el contenido de archivos mayores a 1 MB.

## Corrección aplicada
- Lectura en modo *raw* (`Accept: application/vnd.github.v3.raw`), con `raw.githubusercontent.com` como respaldo.
- `Cache-Control: no-store` y parámetro `_t=` en la URL para evitar mostrar versiones en caché.

## Verificación
- [x] Publicación exitosa con catálogo > 1 MB.
- [x] El cambio se ve de inmediato en la tienda, sin caché.

## Lección para pruebas
Incluir pruebas con **volúmenes de datos realistas y crecientes** (valores límite de tamaño).
